구글 스프레드시트 불러오기

다음 단계에서 연동할 Google Apps Script (웹 앱 URL) 또는 스프레드시트 공유 링크를 입력하여 학생과 역할을 원클릭으로 동기화할 수 있습니다.

설정된 Apps Script 주소를 입력하면 자동으로 학생·역할 목록을 불러옵니다.
💡 Apps Script 연동 코드 가이드 (클릭하여 보기)

스프레드시트 [확장 프로그램] → [Apps Script]에 아래 코드를 붙여넣고 [웹 앱으로 배포]하세요:

function doGet() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  // A열: 학생 이름, B열: 역할명, C열: 이모지, D열: 하는일
  return ContentService.createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}
